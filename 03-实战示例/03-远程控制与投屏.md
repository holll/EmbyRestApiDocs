# 实战三：远程控制与投屏

> [返回总目录](../README.md) ｜ [相关服务：SessionsService](../01-接口参考/04-播放与同步/SessionsService.md)

「手机上选片、电视上播放」是 Emby 客户端的招牌功能。它的实现并不复杂：**谁在播放、能接受什么指令、把指令发给谁**，三个问题对应三个接口。

## 1. 原理：会话（Session）是控制的抓手

每一次「有客户端在播放/在线」，服务端都会建一条 `Session`：

```text
Session {
  Id,                 ← 控制目标（发指令靠它）
  DeviceName, Client, ← 界面上显示的设备
  UserId, UserName,   ← 谁在用
  NowPlayingItem,     ← 正在播什么（可为空 = 只是在线）
  PlayState,          ← 播放/暂停/位置/音量
  SupportedCommands,  ← 这台设备接受哪些指令
  PlayableMediaTypes, ← 能播 Video/Audio/Photo
  SupportsRemoteControl
}
```

控制方要做的事就是：`GET /Sessions` 找到目标会话 → 按它声明的能力发指令。

## 2. 第一步：让本机「可被控制」

被控端启动后要上报自己的能力，否则服务端与遥控端都不知道它能干什么：

```javascript
await api('/Sessions/Capabilities/Full', {
  method: 'POST',
  body: {
    PlayableMediaTypes: ['Video', 'Audio', 'Photo'],
    SupportedCommands: [
      'PlayPause', 'Pause', 'Unpause', 'Stop', 'Seek',
      'NextTrack', 'PreviousTrack', 'VolumeUp', 'VolumeDown',
      'Mute', 'Unmute', 'ToggleMute', 'SetVolume',
      'SetAudioStreamIndex', 'SetSubtitleStreamIndex',
    ],
    SupportsMediaControl: true,
    SupportsRemoteControl: true,
    HasCustomDeviceName: true,
  },
});
```

| 字段 | 作用 |
|---|---|
| `SupportedCommands` | 决定遥控端会显示哪些按钮，**只上报真正实现了的** |
| `PlayableMediaTypes` | 决定「投屏给它」时可选的内容类型 |
| `SupportsRemoteControl` | 为 `false` 时，别的设备控制不了它 |
| `SupportsMediaControl` | 是否支持媒体按钮（播放/暂停/音量） |

> 建议在「启动后」「登录后」「播放器就绪后」各上报一次，服务端据此刷新会话能力。

## 3. 第二步：列出可控制的设备

```javascript
async function listControllableSessions() {
  const sessions = await api('/Sessions', {
    query: { ControllableByUserId: state.userId },   // 只列我可控制的
  });

  return sessions.map(s => ({
    id: s.Id,
    device: s.DeviceName,
    client: s.Client,
    userName: s.UserName,
    nowPlaying: s.NowPlayingItem
      ? {
          name: s.NowPlayingItem.Name,
          type: s.NowPlayingItem.Type,
          position: (s.PlayState?.PositionTicks ?? 0) / TICKS,
          paused: s.PlayState?.IsPaused ?? false,
          volume: s.PlayState?.VolumeLevel ?? 0,
        }
      : null,
    commands: s.SupportedCommands ?? [],
    controllable: s.SupportsRemoteControl !== false,
  }));
}
```

过滤与展示建议：

| 判断 | 用途 |
|---|---|
| `NowPlayingItem` 为空 | 设备在线但空闲 → 可以「投屏给它」 |
| `PlayState.IsPaused` | 决定按钮显示「播放」还是「暂停」 |
| `SupportedCommands` 不含某命令 | 该按钮置灰，不要发 |
| `UserId` 是自己 | 可以控制自己的另一台设备；控制他人需要权限 |

## 4. 第三步：发指令

播放控制统一走 `POST /Sessions/{Id}/Playing/{Command}`：

```javascript
async function sendCommand(sessionId, command, extra = {}) {
  const body = {};
  if (command === 'Seek') body.SeekPositionTicks = Math.round(extra.seconds * TICKS);
  if (extra.command) body.Command = extra.command;
  await api(`/Sessions/${sessionId}/Playing/${command}`, { method: 'POST', body });
}
```

常用命令：

| Command | 作用 | 备注 |
|---|---|---|
| `PlayPause` | 播放/暂停切换 | 最常用，一个按钮搞定 |
| `Pause` / `Unpause` | 明确暂停/继续 | 状态已知时用 |
| `Stop` | 停止播放 | 停止后会话仍在，只是空闲 |
| `Seek` | 跳转 | **必须带 `SeekPositionTicks`**（tick，不是秒） |
| `Rewind` / `FastForward` | 后退/前进 | 步长由被控端决定 |
| `NextTrack` / `PreviousTrack` | 下一首/上一首 | 音乐、连播 |
| `VolumeUp` / `VolumeDown` | 音量 ± | 步长由被控端决定 |
| `Mute` / `Unmute` / `ToggleMute` | 静音控制 | — |
| `SetVolume` | 精确音量 | 带 `VolumeLevel`（0–100） |
| `SetAudioStreamIndex` / `SetSubtitleStreamIndex` | 切换音轨/字幕 | 播放中切轨 |

示例：

```javascript
await sendCommand(target.id, 'PlayPause');

await sendCommand(target.id, 'Seek', { seconds: 600 });   // 跳到第 10 分钟

await api(`/Sessions/${target.id}/Playing/Stop`, { method: 'POST', body: {} });
```

## 5. 投屏：让某台设备播放指定条目

「投屏」= 让目标设备的会话开始播放某个 `ItemId`：

```javascript
async function castTo(sessionId, itemId, { playCommand = 'PlayNow', startSeconds = 0, mediaSourceId } = {}) {
  const q = {
    PlayCommand: playCommand,        // PlayNow / PlayNext / PlayLast / PlayInstantMix / PlayShuffle
    ItemIds: itemId,                 // 多个用逗号分隔
    StartPositionTicks: Math.round(startSeconds * TICKS),
  };
  if (mediaSourceId) q.MediaSourceId = mediaSourceId;
  await api(`/Sessions/${sessionId}/Playing`, { query: q, method: 'POST' });
}
```

| PlayCommand | 语义 |
|---|---|
| `PlayNow` | 立即播放（清空当前队列） |
| `PlayNext` | 插入到下一首 |
| `PlayLast` | 追加到队列末尾 |
| `PlayInstantMix` | 以该条目为种子生成混合播放列表 |
| `PlayShuffle` | 随机播放 |

典型投屏交互：

```text
1. 用户在手机上点「投屏」
2. GET /Sessions?ControllableByUserId=…        列出电视
3. 用户选电视 → POST /Sessions/{tvId}/Playing  { PlayCommand: PlayNow, ItemIds: 选中条目 }
4. 电视端收到指令后自行调 PlaybackInfo 并播放
5. 手机端轮询 GET /Sessions 刷新「电视正在播放 X」
```

> 注意：**投屏不是把 URL 推给对方**，而是把 `ItemId` 交给对方的会话，由对方自己按本机能力取播放地址。这样才能自动适配电视的编码能力。

## 6. 让目标设备「跳转界面」

有时你想让电视打开某个条目详情页，而不是直接播放：

```javascript
await api(`/Sessions/${sessionId}/Viewing`, {
  method: 'POST',
  query: { ItemId: itemId, ItemType: 'Movie' },
});
```

对应的服务页见 [SessionsService](../01-接口参考/04-播放与同步/SessionsService.md) 的「指示会话跳转到条目或视图」。

## 7. 弹出提示 / 系统命令

```javascript
// 在目标屏幕弹一条消息（类似「已从手机投屏」）
await api(`/Sessions/${sessionId}/Message`, {
  method: 'POST',
  query: { Text: '正在从手机投屏…', Header: '提示', TimeoutMs: 3000 },
});

// 系统级命令（如重启客户端界面、查询系统信息）
await api(`/Sessions/${sessionId}/Command/DisplayMessage`, {
  method: 'POST',
  query: { Text: 'Hello' },
});
```

`Command` 的可选值取决于目标端实现，常见的系统命令包括 `DisplayMessage`、`SetVolume`、`SystemInfo`、`SendString`。**发之前先用 `SupportedCommands` 判断**。

## 8. 谁在播什么：状态面板

遥控面板需要定时刷新。轮询间隔建议：

| 场景 | 间隔 |
|---|---|
| 面板打开且正在播放 | 2–3 秒 |
| 面板打开但空闲 | 5–10 秒 |
| 面板关闭 | 停止轮询 |

```javascript
let timer = null;
function startPolling(onUpdate) {
  stopPolling();
  timer = setInterval(async () => onUpdate(await listControllableSessions()), 3000);
}
function stopPolling() { if (timer) clearInterval(timer); timer = null; }
```

> Emby 没有为会话状态提供 WebSocket 推送，客户端都是轮询。为避免耗电，面板不可见时务必停掉。

## 9. 权限：能控制谁

| 条件 | 结果 |
|---|---|
| 同一用户的不同设备 | 默认可控制 |
| 控制其他用户的设备 | 需要 `Policy.EnableRemoteControlOfOtherUsers = true` |
| 目标 `SupportsRemoteControl = false` | 不可控制（如纯 DLNA 渲染器、Web 只读会话） |
| 目标会话已结束 | `GET /Sessions` 里消失，指令返回 404 |

## 10. 完整代码骨架

```javascript
// 被控端：启动时上报能力
async function becomeControllable() {
  await api('/Sessions/Capabilities/Full', {
    method: 'POST',
    body: {
      PlayableMediaTypes: ['Video', 'Audio', 'Photo'],
      SupportedCommands: ['PlayPause', 'Pause', 'Unpause', 'Stop', 'Seek',
                          'VolumeUp', 'VolumeDown', 'Mute', 'Unmute', 'SetVolume'],
      SupportsMediaControl: true,
      SupportsRemoteControl: true,
    },
  });
}

// 遥控端：投屏 + 控制
async function castFlow(itemId) {
  const targets = await listControllableSessions();
  const tv = targets.find(t => t.controllable && t.device.includes('TV'));
  if (!tv) throw new Error('没有找到可投屏的电视');

  await castTo(tv.id, itemId, { playCommand: 'PlayNow' });
  startPolling(list => renderDevices(list));
}

// 遥控端：按钮
async function onPlayPause(session) {
  if (!session.commands.includes('PlayPause')) return;   // 能力不匹配就别发
  await sendCommand(session.id, 'PlayPause');
}

async function onSeek(session, seconds) {
  if (!session.commands.includes('Seek')) return;
  await sendCommand(session.id, 'Seek', { seconds });
}
```

## 11. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `GET /Sessions` 看不到电视 | 电视端没上报能力、或已退出登录 | 让被控端调 `Capabilities/Full` |
| 指令返回 200 但没反应 | 命令不在目标 `SupportedCommands` 里 | 按能力列表渲染按钮 |
| 投屏后电视播的还是旧的 | `PlayCommand` 用了 `PlayLast` | 改用 `PlayNow` |
| 拖动进度失败 | `SeekPositionTicks` 传成了秒 | 乘 `10,000,000` 换成 tick |
| 控制他人设备 403 | 缺少 `EnableRemoteControlOfOtherUsers` | 管理员在用户策略里开启 |
| 会话 ID 失效 | 会话随客户端退出而消失 | 每次操作前重新拉 `/Sessions` |
