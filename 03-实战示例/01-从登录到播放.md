# 实战一：从登录到播放

> [返回总目录](../README.md) ｜ [相关基础篇：快速开始](../00-基础/01-快速开始.md)

本文把一条完整链路写成可直接跑的代码：**登录 → 取视图 → 取列表 → 取详情 → 取播放地址 → 播放 → 上报进度**。示例用 JavaScript（Node / 浏览器通用），接口细节点进对应服务页查看。

## 0. 前置：统一的请求封装

```javascript
const TICKS = 10_000_000;

const state = {
  baseUrl: 'http://192.168.1.10:8096',
  deviceId: 'my-client-7f3a91',       // 必须持久化，不要每次启动重生成
  client: 'MyClient',
  device: 'PC',
  version: '1.0.0',
  token: null,
  userId: null,
  sessionId: null,
};

function authHeader(extra = {}) {
  const parts = [
    `Client="${state.client}"`,
    `Device="${state.device}"`,
    `DeviceId="${state.deviceId}"`,
    `Version="${state.version}"`,
  ];
  if (state.userId) parts.unshift(`UserId="${state.userId}"`);
  if (state.token) parts.push(`Token="${state.token}"`);
  return 'Emby ' + parts.join(', ');
}

async function api(path, { method = 'GET', body, query } = {}) {
  const url = new URL(state.baseUrl + path);
  if (query) for (const [k, v] of Object.entries(query)) {
    if (v !== undefined && v !== null) url.searchParams.set(k, v);
  }
  const headers = { 'Accept': 'application/json', 'X-Emby-Authorization': authHeader() };
  if (body) headers['Content-Type'] = 'application/json';
  const res = await fetch(url, {
    method, headers, body: body ? JSON.stringify(body) : undefined,
  });
  if (!res.ok) throw new Error(`${method} ${path} → HTTP ${res.status}`);
  const text = await res.text();
  return text ? JSON.parse(text) : null;
}
```

## 1. 登录

```javascript
async function login(username, password) {
  const data = await api('/Users/AuthenticateByName', {
    method: 'POST',
    body: { Username: username, Pw: password },
  });
  state.token = data.AccessToken;
  state.userId = data.User.Id;
  state.sessionId = data.SessionInfo?.Id ?? null;
  localStorage.setItem('emby.token', state.token);
  localStorage.setItem('emby.userId', state.userId);
  return data.User;
}
```

## 2. 取首页视图

```javascript
async function loadViews() {
  const q = await api(`/Users/${state.userId}/Views`);
  return q.Items.map(v => ({
    id: v.Id,
    name: v.Name,
    type: v.CollectionType,   // movies / tvshows / music / books / photos …
  }));
}
```

## 3. 取列表（海报墙）

```javascript
async function loadList(viewId, { start = 0, limit = 24 } = {}) {
  const q = await api(`/Users/${state.userId}/Items`, {
    query: {
      ParentId: viewId,
      Recursive: 'true',
      IncludeItemTypes: 'Movie',
      SortBy: 'DateCreated',
      SortOrder: 'Descending',
      StartIndex: start,
      Limit: limit,
      Fields: 'PrimaryImageAspectRatio,ProductionYear',   // 只取列表页需要的轻字段
    },
  });
  return { items: q.Items, total: q.TotalRecordCount, start: q.StartIndex };
}
```

要点：`TotalRecordCount` 用来算总页数；`Fields` 只放轻字段；**不要在列表页请求 `MediaSources`/`People`**。

## 4. 取详情

```javascript
async function loadDetail(itemId) {
  const d = await api(`/Users/${state.userId}/Items/${itemId}`, {
    query: { Fields: 'MediaSources,MediaStreams,People,Overview,ProviderIds,Taglines' },
  });
  return d;   // BaseItemDto
}
```

详情页才有意义展示：简介、演职人员、音轨字幕、媒体源（`MediaSources[].Container`、`.Bitrate`、`.Size`）。

## 5. 取播放地址

```javascript
function buildDeviceProfile() {
  return {
    MaxStreamingBitrate: 120_000_000,
    DirectPlayProfiles: [
      { Container: 'mp4,mkv,webm', Type: 'Video', VideoCodec: 'h264,hevc,vp9', AudioCodec: 'aac,mp3,opus,flac' },
      { Container: 'mp3,flac,aac', Type: 'Audio' },
    ],
    TranscodingProfiles: [
      { Container: 'mp4', Type: 'Video', AudioCodec: 'aac', VideoCodec: 'h264', Context: 'Streaming', Protocol: 'hls' },
    ],
    SubtitleProfiles: [ { Format: 'vtt', Method: 'External' } ],
  };
}

async function getPlaybackInfo(itemId, { mediaSourceId, startTicks = 0 } = {}) {
  const r = await api(`/Items/${itemId}/PlaybackInfo`, {
    method: 'POST',
    query: { UserId: state.userId, StartTimeTicks: startTicks, MediaSourceId: mediaSourceId },
    body: { DeviceProfile: buildDeviceProfile() },
  });

  const src = r.MediaSources?.[0];
  if (!src) throw new Error('该条目没有可用的媒体源');
  return {
    playSessionId: r.PlaySessionId,
    mediaSourceId: src.Id,
    url: src.TranscodingUrl
      ? state.baseUrl + src.TranscodingUrl
      : state.baseUrl + src.DirectStreamUrl,
    runTimeTicks: src.RunTimeTicks ?? 0,
    isTranscoding: !!src.TranscodingUrl,
  };
}
```

`PlaybackInfoResponse` 的关键字段：

| 字段 | 说明 |
|---|---|
| `PlaySessionId` | 整场播放复用的会话 ID，上报进度必带 |
| `MediaSources[].Id` | 媒体源 ID（多版本时用它选版本） |
| `MediaSources[].DirectStreamUrl` | 直连地址（原文件或仅转封装） |
| `MediaSources[].TranscodingUrl` | 转码地址（HLS / 流式），存在即表示需要转码 |
| `MediaSources[].RunTimeTicks` | 时长（tick） |
| `ErrorCode` | 非空表示没有可用媒体源，如 `NotAllowed`、`NoCompatibleStream` |

## 6. 播放

播放器拿到 URL 后**必须同样带令牌**，否则 401：

```javascript
function attachAuth(url) {
  const u = new URL(url);
  u.searchParams.set('api_key', state.token);   // 流媒体请求无法加自定义头时的兜底
  return u.toString();
}
```

```javascript
// 以 <video> 为例
const info = await getPlaybackInfo('c9e1a2b3...', { startTicks: 0 });
video.src = attachAuth(info.url);
video.play();
```

> HLS 转码时 `TranscodingUrl` 指向 `master.m3u8`，需要播放器支持 HLS（浏览器可用 hls.js）。若 `DirectStreamUrl` 指向 `stream` 端点，则是原文件直连。

## 7. 上报进度

三个接口，字段同属 `PlaybackStartInfo` 体系，区别只是「开始 / 进行中 / 结束」：

```javascript
function playbackBody(extra = {}) {
  return {
    ItemId: current.itemId,
    MediaSourceId: current.mediaSourceId,
    PlaySessionId: current.playSessionId,
    PositionTicks: Math.round(video.currentTime * TICKS),
    IsPaused: video.paused,
    IsMuted: video.muted,
    VolumeLevel: Math.round(video.volume * 100),
    CanSeek: true,
    PlayMethod: current.isTranscoding ? 'Transcode' : 'DirectStream',
    ...extra,
  };
}

async function reportStart()  { await api('/Sessions/Playing', { method: 'POST', body: playbackBody() }); }
async function reportProgress() { await api('/Sessions/Playing/Progress', { method: 'POST', body: playbackBody() }); }
async function reportStop()   { await api('/Sessions/Playing/Stopped',  { method: 'POST', body: playbackBody() }); }
```

节奏建议：

| 时机 | 调用 |
|---|---|
| 开始播放 / 换集 | `POST /Sessions/Playing` |
| 播放中 | `POST /Sessions/Playing/Progress`，**每 10 秒一次**（暂停时改为 `Ping`） |
| 暂停 / 恢复 / 拖动进度 | 立即调一次 `Progress` |
| 停止 / 退出播放器 | `POST /Sessions/Playing/Stopped`（否则服务端会一直显示「正在播放」） |

完整调用序列：

```text
login
  └─ loadViews
       └─ loadList(viewId)
            └─ loadDetail(itemId)
                 └─ getPlaybackInfo(itemId)          → PlaySessionId / MediaSourceId / url
                      └─ video.play()
                           ├─ reportStart()
                           ├─ setInterval(reportProgress, 10s)
                           └─ onExit → reportStop()
```

## 8. 断点续播

「继续观看」列表来自 `/Users/{UserId}/Items/Resume`，每项的 `UserData.PlaybackPositionTicks` 就是上次位置：

```javascript
const resume = await api(`/Users/${state.userId}/Items/Resume`, {
  query: { Limit: 12, Fields: 'PrimaryImageAspectRatio' },
});
for (const it of resume.Items) {
  const sec = (it.UserData?.PlaybackPositionTicks ?? 0) / TICKS;
  const total = (it.RunTimeTicks ?? 0) / TICKS;
  console.log(it.Name, `${(sec / total * 100).toFixed(1)}%`);
}
```

再次播放时把秒数换算成 tick 传给 `StartTimeTicks`：

```javascript
const info = await getPlaybackInfo(itemId, { startTicks: Math.round(sec * TICKS) });
```

```bash

curl -X POST "$BASE/Items/<itemId>/PlaybackInfo?UserId=$UID_" \
  -H "X-Emby-Token: $TOKEN" -H 'Content-Type: application/json' \
  -d '{"DeviceProfile":{"MaxStreamingBitrate":120000000,"DirectPlayProfiles":[{"Container":"mp4,mkv","Type":"Video"}]}}'
curl -X POST "$BASE/Sessions/Playing" -H "X-Emby-Token: $TOKEN" -H 'Content-Type: application/json' \
  -d '{"ItemId":"<itemId>","PlaySessionId":"<psid>","PositionTicks":0,"CanSeek":true}'
```

## 10. 常见失败点

| 现象 | 原因 |
|---|---|
| `PlaybackInfo` 的 `MediaSources` 为空 | 条目只有元数据、文件被移走、或用户无权访问该媒体库 |
| 播放 401 | 播放 URL 没带 `api_key`/`X-Emby-Token` |
| 播放 404 | URL 拼接错误（`DirectStreamUrl` 已是相对路径，别再加 `/emby`） |
| 「正在播放」不消失 | 没调 `Sessions/Playing/Stopped` |
| 进度不更新 | `Progress` 请求缺 `PlaySessionId`，或 `PositionTicks` 一直没变 |
| 换集后进度串台 | `PlaySessionId` 没重新从新的 `PlaybackInfo` 取 |
