# SessionsService 会话与远程控制服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/SessionsService.html> ｜ 上级目录：[会话与远程控制服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

当前在线会话列表、会话详情，以及对客户端的远程控制：播放/暂停/跳转、下发消息、跳转浏览、添加附加用户，还有 API 密钥（Auth/Keys）管理。做投屏、遥控、多端同步时必用。

- 接口数量：**20**
- 收录范围：当前官方文档快照中的 20 个端点；不代表已逐接口实机验证。

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `DELETE` | `/Auth/Keys/{Key}` | 删除 API 密钥 | 管理员 |
| 2 | `DELETE` | `/Sessions/{Id}/Users/{UserId}` | 从会话移除附加用户 | 用户 |

| 4 | `GET` | `/Auth/Providers` | 获取可用的认证提供方 | 管理员 |
