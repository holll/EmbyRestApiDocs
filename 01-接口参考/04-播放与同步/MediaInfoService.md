# MediaInfoService 播放信息与媒体源服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/MediaInfoService.html> ｜ 上级目录：[播放信息与媒体源服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

播放链路的核心：`PlaybackInfo` 返回可用的媒体源、转码参数与播放会话 ID；还提供打开/关闭媒体源、直播流媒体信息、带宽测速。任何自研播放器都要先调 PlaybackInfo。

- 接口数量：**6**
- 覆盖范围：官方参考站该服务下的全部 6 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/Items/{Id}/PlaybackInfo` | 获取条目的实时播放媒体信息 | 用户 |
| 2 | `GET` | `/Playback/BitrateTest` | 带宽测速（返回指定大小的数据） | 用户 |
| 3 | `POST` | `/Items/{Id}/PlaybackInfo` | 获取条目的实时播放媒体信息 | 用户 |
| 4 | `POST` | `/LiveStreams/Close` | 关闭媒体源 | 用户 |
| 5 | `POST` | `/LiveStreams/MediaInfo` | 获取直播流的媒体信息 | 用户 |
| 6 | `POST` | `/LiveStreams/Open` | 打开媒体源 | 用户 |

## 1. 获取条目的实时播放媒体信息

`GET` `/Items/{Id}/PlaybackInfo`

- **权限**：用户令牌
- **成功响应**：`200` → `PlaybackInfoResponse`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 条目 ID。 |
| `UserId` | query | string | 否 | 用户 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `PlaybackInfoResponse` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`PlaybackInfoResponse`](../../02-数据模型/04-播放与转码.md#playbackinforesponse)
