# ItemUpdateService 条目更新服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/ItemUpdateService.html> ｜ 上级目录：[条目更新服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

以“元数据编辑器”的方式读取和写回条目字段（标题、简介、年份、评分等），并可指定刷新模式。

- 接口数量：**2**
- 覆盖范围：官方参考站该服务下的全部 2 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/Items/{ItemId}/MetadataEditor` | 获取条目的元数据编辑信息 | 用户 |
| 2 | `POST` | `/Items/{ItemId}` | 更新条目 | 用户 |

---

## 1. 获取条目的元数据编辑信息

`GET` `/Items/{ItemId}/MetadataEditor`

- **权限**：用户令牌
- **成功响应**：`200` → `MetadataEditorInfo`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `ItemId` | path | string | 是 | 条目 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `MetadataEditorInfo` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`MetadataEditorInfo`](../../02-数据模型/02-媒体条目.md#metadataeditorinfo)

> 该接口在官方文档中还引用了 4 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。

## 2. 更新条目

`POST` `/Items/{ItemId}`

- **权限**：用户令牌
- **成功响应**：`200`（无返回内容）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `ItemId` | path | string | 是 | 条目 ID。 |
| `body` | body | BaseItemDto | — | 请求体：`BaseItemDto` 对象。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，无返回内容 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`BaseItemDto`](../../02-数据模型/02-媒体条目.md#baseitemdto)
