# UniversalAudioService 通用音频服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/UniversalAudioService.html> ｜ 上级目录：[通用音频服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

按“通用音频”路径输出音频流，常用于有声书、播客等场景。

- 接口数量：**4**
- 覆盖范围：官方参考站该服务下的全部 4 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/Audio/{Id}/universal` | 获取音频流 | 用户 |
| 2 | `GET` | `/Audio/{Id}/universal.{Container}` | 获取音频流 | 用户 |
| 3 | `HEAD` | `/Audio/{Id}/universal` | 获取音频流 | 用户 |
| 4 | `HEAD` | `/Audio/{Id}/universal.{Container}` | 获取音频流 | 用户 |

---

## 1. 获取音频流

`GET` `/Audio/{Id}/universal`

- **权限**：用户令牌
- **成功响应**：`200`（二进制内容，如文件流、图片或字幕）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 条目 ID。 |
| `DeviceId` | query | string | 否 | 请求方客户端的设备 ID，用于在需要时终止转码进程。 |
| `StartTimeTicks` | query | integer | 否 | 可选。起始偏移，单位 tick，1 毫秒 = 10000 ticks。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |
