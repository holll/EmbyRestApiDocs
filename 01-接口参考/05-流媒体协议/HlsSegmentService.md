# HlsSegmentService HLS 编码任务服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/HlsSegmentService.html> ｜ 上级目录：[HLS 编码任务服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

管理正在进行的 HLS 编码任务：停止/删除活动编码，避免转码进程堆积。

- 接口数量：**2**
- 收录范围：当前官方文档快照中的 2 个端点；不代表已逐接口实机验证。

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `DELETE` | `/Videos/ActiveEncodings` | 停止活动的 HLS 编码任务 | 用户 |
| 2 | `POST` | `/Videos/ActiveEncodings/Delete` | 删除活动的 HLS 编码任务 | 用户 |

---

## 1. 停止活动的 HLS 编码任务

`DELETE` `/Videos/ActiveEncodings`

- **权限**：用户令牌
- **成功响应**：`200`（无返回内容，动作类接口）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `DeviceId` | query | string | 是 | 请求方客户端的设备 ID，用于在需要时终止转码进程。 |
| `PlaySessionId` | query | string | 是 | 播放会话 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

---
