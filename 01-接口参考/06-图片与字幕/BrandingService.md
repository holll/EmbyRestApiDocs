# BrandingService 品牌配置服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/BrandingService.html> ｜ 上级目录：[品牌配置服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

服务器品牌信息：自定义 CSS、服务器图标等，用于让客户端与服务器外观一致。

- 接口数量：**3**
- 覆盖范围：官方参考站该服务下的全部 3 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/Branding/Configuration` | 获取品牌配置 | 用户 |
| 2 | `GET` | `/Branding/Css` | 获取自定义 CSS | 用户 |
| 3 | `GET` | `/Branding/Css.css` | 获取自定义 CSS | 用户 |

---

## 1. 获取品牌配置

`GET` `/Branding/Configuration`

- **权限**：用户令牌
- **成功响应**：`200` → `BrandingOptions`

该接口无请求参数。

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `BrandingOptions` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`BrandingOptions`](../../02-数据模型/06-系统与配置.md#brandingoptions)
