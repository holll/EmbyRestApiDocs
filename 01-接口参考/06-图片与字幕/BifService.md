# BifService BIF 缩略图服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/BifService.html> ｜ 上级目录：[BIF 缩略图服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

生成/获取 BIF 索引文件（视频进度条预览图），电视端与部分播放器用它做拖动预览。

- 接口数量：**2**
- 覆盖范围：官方参考站该服务下的全部 2 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/Items/{Id}/ThumbnailSet` | 获取条目的缩略图集（BIF） | 用户 |
| 2 | `GET` | `/Videos/{Id}/index.bif` | 获取视频的 BIF 索引文件 | 用户 |

---

## 1. 获取条目的缩略图集（BIF）

`GET` `/Items/{Id}/ThumbnailSet`

- **权限**：用户令牌
- **成功响应**：`200` → `ThumbnailSetInfo`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Width` | query | integer | 否 | — |
| `Id` | path | string | 是 | 条目 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `ThumbnailSetInfo` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`ThumbnailSetInfo`](../../02-数据模型/02-媒体条目.md#thumbnailsetinfo)

> 该接口在官方文档中还引用了 1 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。

## 2. 获取视频的 BIF 索引文件

`GET` `/Videos/{Id}/index.bif`

- **权限**：用户令牌
- **成功响应**：`200`（二进制内容，如文件流、图片或字幕）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Width` | query | integer | 否 | — |
| `Id` | path | string | 是 | 条目 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |
