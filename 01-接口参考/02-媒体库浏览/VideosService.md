# VideosService 视频条目服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/VideosService.html> ｜ 上级目录：[视频条目服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

视频条目的补充操作：多版本合并为一条记录、获取附加分段（如 CD 分段、花絮）。

- 接口数量：**3**
- 覆盖范围：官方参考站该服务下的全部 3 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `DELETE` | `/Videos/{Id}/AlternateSources` | 移除备用视频源 | 管理员 |
| 2 | `POST` | `/Videos/{Id}/AlternateSources/Delete` | 移除备用视频源 | 管理员 |
| 3 | `POST` | `/Videos/MergeVersions` | 把多个视频合并为一条记录 | 管理员 |

---

## 1. 移除备用视频源

`DELETE` `/Videos/{Id}/AlternateSources`

- **权限**：管理员令牌
- **成功响应**：`200`（无返回内容）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 条目 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，无返回内容 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |
