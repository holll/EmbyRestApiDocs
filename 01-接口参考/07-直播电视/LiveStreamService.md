# LiveStreamService 直播流服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/LiveStreamService.html> ｜ 上级目录：[直播流服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

打开/关闭直播流、获取直播媒体信息、媒体源管理。直播播放前通常先在这里拿到 LiveStreamId，再去流媒体接口取流。

- 接口数量：**14**
- 收录范围：当前官方文档快照中的 14 个端点；不代表已逐接口实机验证。

## 1. 获取直播录制项

`GET` `/LiveTv/LiveRecordings/{Id}/hls/{Segment}`

- **权限**：用户令牌
- **成功响应**：`200`（二进制内容，如文件流、图片或字幕）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 条目 ID |
| `Segment` | path | string | 是 | 路径参数 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求无法被服务器处理 |
