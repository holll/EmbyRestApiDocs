---

## 1. 获取已安装的功能特性

`GET` `/Features`

- **权限**：管理员令牌
- **成功响应**：`200` → `FeatureInfo []`

该接口无请求参数。

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `FeatureInfo []` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`FeatureInfo`](../../02-数据模型/06-系统与配置.md#featureinfo)、[`FeatureType`](../../02-数据模型/06-系统与配置.md#featuretype)
