# PackageService 插件包服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/PackageService.html> ｜ 上级目录：[插件包服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

插件市场：查询可用包与更新、安装/取消安装。

- 接口数量：**6**
- 覆盖范围：官方参考站该服务下的全部 6 个端点

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `DELETE` | `/Packages/Installing/{Id}` | 取消包安装 | 管理员 |
| 2 | `GET` | `/Packages` | 获取可用包列表 | 用户 |
| 3 | `GET` | `/Packages/{Name}` | 按名称或程序集 GUID 获取包 | 用户 |
| 4 | `GET` | `/Packages/Updates` | 获取已安装包的可用更新 | 管理员 |
| 5 | `POST` | `/Packages/Installed/{Name}` | 安装包 | 管理员 |
| 6 | `POST` | `/Packages/Installing/{Id}/Delete` | 取消包安装 | 管理员 |

---

## 1. 取消包安装

`DELETE` `/Packages/Installing/{Id}`

- **权限**：管理员令牌
- **成功响应**：`200`（无返回内容）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 安装 ID。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，无返回内容 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

---

## 2. 获取可用包列表

`GET` `/Packages`

- **权限**：用户令牌
- **成功响应**：`200` → `PackageInfo []`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `PackageType` | query | string | 否 | 可选。包类型过滤（System 系统内置 / UserInstalled 用户安装）。 |
| `TargetSystems` | query | string | 否 | 可选。按目标系统类型过滤，英文逗号分隔多个。 |
| `IsPremium` | query | boolean | 否 | 可选。按是否为高级（Premium）功能过滤。 |
| `IsAdult` | query | boolean | 否 | 可选。筛选是否包含成人内容的包。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `PackageInfo []` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`PackageInfo`](../../02-数据模型/06-系统与配置.md#packageinfo)、[`PackageTargetSystem`](../../02-数据模型/06-系统与配置.md#packagetargetsystem)

> 该接口在官方文档中还引用了 2 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。

## 5. 安装包

`POST` `/Packages/Installed/{Name}`

- **权限**：管理员令牌
- **成功响应**：`200`（无返回内容）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Name` | path | string | 是 | 包名称。 |
| `AssemblyGuid` | query | string | 否 | 关联程序集的 GUID。 |
| `Version` | query | string | 否 | 可选。版本号，默认取最新版本。 |
| `UpdateClass` | query | string | 否 | 可选。更新通道（Dev、Beta、Release），默认 Release。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，无返回内容 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |
