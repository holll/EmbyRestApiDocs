# ScheduledTaskService 计划任务服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/ScheduledTaskService.html> ｜ 上级目录：[计划任务服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

服务器内置计划任务：列出任务、查看详情、启停、修改触发器。做“扫描媒体库”按钮时通常调这里。

- 接口数量：**6**
- 收录范围：当前官方文档快照中的 6 个端点；不代表已逐接口实机验证。

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `DELETE` | `/ScheduledTasks/Running/{Id}` | 停止计划任务 | 管理员 |
| 2 | `GET` | `/ScheduledTasks` | 获取计划任务列表 | 管理员 |
| 3 | `GET` | `/ScheduledTasks/{Id}` | 按 ID 获取计划任务 | 管理员 |
| 4 | `POST` | `/ScheduledTasks/{Id}/Triggers` | 更新计划任务的触发器 | 管理员 |
| 5 | `POST` | `/ScheduledTasks/Running/{Id}` | 启动计划任务 | 管理员 |
| 6 | `POST` | `/ScheduledTasks/Running/{Id}/Delete` | 停止计划任务 | 管理员 |

---

## 1. 停止计划任务

`DELETE` `/ScheduledTasks/Running/{Id}`

- **权限**：管理员令牌
- **成功响应**：`200`（无返回内容）

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `Id` | path | string | 是 | 条目 ID |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，无返回内容 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

## 2. 获取计划任务列表

`GET` `/ScheduledTasks`

- **权限**：管理员令牌
- **成功响应**：`200` → `TaskInfo []`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `IsHidden` | query | boolean | 否 | 可选。按是否隐藏筛选任务。 |
| `IsEnabled` | query | boolean | 否 | 可选。按是否启用筛选任务。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `TaskInfo []` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`TaskInfo`](../../02-数据模型/02-媒体条目.md#taskinfo)、[`TaskState`](../../02-数据模型/02-媒体条目.md#taskstate)

> 该接口在官方文档中还引用了 5 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。
