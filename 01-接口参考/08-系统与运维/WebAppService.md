# WebAppService Web 前端资源服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/WebAppService.html> ｜ 上级目录：[Web 前端资源服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

Web 管理界面用的配置页面与界面文案接口。第三方客户端一般不需要。

- 接口数量：**4**
- 收录范围：当前官方文档快照中的 4 个端点；不代表已逐接口实机验证。

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/web/ConfigurationPage` | 获取配置页面 | 用户 |
| 2 | `GET` | `/web/ConfigurationPages` | 获取配置页面列表 | 用户 |
| 3 | `GET` | `/web/strings` | 获取界面文案（JSON） | 用户 |
| 4 | `GET` | `/web/stringset` | 获取界面文案（字符串集） | 用户 |

---

## 1. 获取配置页面

`GET` `/web/ConfigurationPage`

- **权限**：用户令牌
- **成功响应**：`200`（二进制内容，如文件流、图片或字幕）

该接口无请求参数。

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

---

## 2. 获取配置页面列表

`GET` `/web/ConfigurationPages`

- **权限**：用户令牌
- **成功响应**：`200` → `ConfigurationPageInfo []`

该接口无请求参数。

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `ConfigurationPageInfo []` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`ConfigurationPageInfo`](../../02-数据模型/06-系统与配置.md#configurationpageinfo)、[`ConfigurationPageType`](../../02-数据模型/06-系统与配置.md#configurationpagetype)

> 该接口在官方文档中还引用了 2 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。
