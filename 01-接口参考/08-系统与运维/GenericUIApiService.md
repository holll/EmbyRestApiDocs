# GenericUIApiService 通用 UI 接口服务

> 官方文档：<https://dev.emby.media/reference/RestAPI/GenericUIApiService.html> ｜ 上级目录：[通用 UI 接口服务](README.md) ｜ [返回总目录](../../README.md)

## 概述

为 Web 端 UI 提供聚合数据与命令执行（如电视设置向导中的命令）。

- 接口数量：**2**
- 收录范围：当前官方文档快照中的 2 个端点；不代表已逐接口实机验证。

## 接口一览

| # | 方法 | 路径 | 说明 | 权限 |
|---:|---|---|---|---|
| 1 | `GET` | `/UI/View` | 获取 UI 视图数据 | 管理员 |
| 2 | `POST` | `/UI/Command` | 在电视设置流程中执行命令 | 管理员 |

---

## 1. 获取 UI 视图数据

`GET` `/UI/View`

- **权限**：管理员令牌
- **成功响应**：`200` → `UIViewInfo`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `PageId` | query | string | 是 | 页面控制器 ID。 |
| `ClientLocale` | query | string | 是 | 客户端区域标识（如 zh-CN）。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `UIViewInfo` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`UIViewInfo`](../../02-数据模型/06-系统与配置.md#uiviewinfo)

> 该接口在官方文档中还引用了 5 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。

## 2. 在电视设置流程中执行命令

`POST` `/UI/Command`

- **权限**：管理员令牌
- **成功响应**：`200` → `UIViewInfo`

**请求参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `body` | body | RunUICommand | 是 | 请求体：`RunUICommand` 对象。 |

**响应**

| 状态码 | 说明 |
|---|---|
| 200 | 成功，返回 `UIViewInfo` |
| 400 | 请求无法被服务器处理 |
| 401 | 未认证，或令牌已失效 |
| 403 | 已认证但无权限执行该操作 |
| 404 | 资源不存在或不可用 |
| 500 | 服务器内部错误 |

**涉及的数据模型**

[`UIViewInfo`](../../02-数据模型/06-系统与配置.md#uiviewinfo)、[`RunUICommand`](../../02-数据模型/06-系统与配置.md#runuicommand)

> 该接口在官方文档中还引用了 5 个辅助模型，可在 [模型索引](../../02-数据模型/00-模型索引.md) 中按名称查找。
