# 常用接口速查表

> [返回总目录](../README.md) ｜ [上一篇：错误处理与排查](04-错误与排查.md)

按「一个第三方客户端要做的事」组织，而不是按服务名。每条给出方法 + 路径 + 一句话说明 + 详细文档链接。参数细节请点进对应服务页。

## 11. 客户端启动时的最小调用序列

```text
1. GET  /System/Info/Public            确认服务器、拿 ServerId、版本
2. POST /Users/AuthenticateByName      登录，拿 AccessToken / UserId / SessionId
3. GET  /Users/{UserId}                读 Policy，决定显示哪些功能入口
4. POST /Sessions/Capabilities/Full    上报本机能力（做远程控制端时必须）
5. GET  /Users/{UserId}/Views          渲染首页导航
6. GET  /Users/{UserId}/Items/Resume   渲染「继续观看」
7. GET  /Users/{UserId}/Items/Latest   渲染「最近添加」
```

退出时：

```text
POST /Sessions/Logout                  告知服务端会话结束（可选但推荐）
```

## 12. 按任务找接口

| 我要做… | 用这些接口 |
|---|---|
| 登录页（含公开用户头像） | `/Users/Public` → `/Users/{Id}/Images/Primary` → `/Users/AuthenticateByName` |
| 首页海报墙 | `/Users/{UserId}/Views` → `/Users/{UserId}/Items`（`Fields=PrimaryImageAspectRatio`） |
| 详情页 | `/Users/{UserId}/Items/{Id}`（`Fields=MediaSources,MediaStreams,People,Overview`） |
| 剧集分集 | `/Shows/{Id}/Seasons` → `/Shows/{Id}/Episodes` |
| 搜索 | `/Users/{UserId}/Items?SearchTerm=`（结果页）+ `/Users/{UserId}/SearchedItems/`（上报搜索行为） |
| 播放 | `POST /Items/{Id}/PlaybackInfo` → 播放 `DirectStreamUrl`/`TranscodingUrl` |
| 进度同步 | `POST /Sessions/Playing` → `/Progress` → `/Stopped` |
| 投屏/遥控 | `GET /Sessions` → `POST /Sessions/{Id}/Playing/{Command}` |
| 收藏/已看 | `POST /Users/{UserId}/FavoriteItems/{Id}`、`/PlayedItems/{Id}` |
| 下载 | `GET /Items/{Id}/Download`（需 `Policy.EnableContentDownloading`） |
| 离线同步 | `GET /Sync/Jobs`、`POST /Sync/Jobs`、`GET /Sync/Items/Ready`（见 [SyncService](../01-接口参考/04-播放与同步/SyncService.md)） |
